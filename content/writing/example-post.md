This is an example post. You can delete this file and create your own markdown files in the `content/writing/` directory.

## How to add a new post

1. Create a new `.md` file in `content/writing/`
2. Add frontmatter with `title`, `date`, and `excerpt`
3. Write your content below using markdown

The posts will automatically appear on the Writing page, organized by year.
